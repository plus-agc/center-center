# 弘前大学医学部附属病院 腫瘍センター（静的サイト）

Webpack でビルドする **静的 HTML/CSS/JavaScript** のプロジェクトです。**本番はさくらインターネットのサーバー（レンタルサーバ等）** に `dist` を公開する運用を想定しています（PHP・DB は不要）。

## 技術スタック

- **Node.js** + **Webpack 5**
- マルチページ HTML（`index.html` ほか）
- ニュース・イベントなど一部コンテンツはクライアントから **microCMS** の API を `fetch`（`js/news.js` / `js/event.js`）

## 必要環境

- Node.js（プロジェクトの Webpack 5 が動作する LTS 推奨）
- npm

## セットアップ

```bash
npm ci
# または
npm install
```

## よく使うコマンド

| コマンド        | 説明                                                            |
| --------------- | --------------------------------------------------------------- |
| `npm run dev`   | 開発サーバー起動（`webpack.config.dev.js`、ブラウザで開きます） |
| `npm run build` | 本番用ビルド。成果物は **`dist/`** に出力                       |

ビルド後は `dist/` 以下がそのまま公開用の静的ファイルです。

## さくらサーバーへのデプロイ（概要）

1. ローカルまたは CI で `npm run build` を実行する。
2. **`dist/` 配下すべて**を、さくらの **ドキュメントルート（公開ディレクトリ）** にアップロードする（FTP / SFTP / rsync 等）。
3. コントロールパネルから **SSL（無料証明書等）** を有効化する。
4. 必要に応じて **`404.html`** と **`.htaccess`**（`ErrorDocument 404`）を公開ルートで確認する。

FTP パスワードやサーバー接続情報は **リポジトリに含めない**でください（個人の設定・CI のシークレットで管理）。

## 本番 URL・サイトマップ

本番ビルドでは `sitemap.xml` 用のベース URL が `webpack.config.prod.js` の `SitemapPlugin` で設定されています。**ドメインやパスを変える場合は `base` を必ず本番に合わせて更新**してください。

運用イメージ・工数目安・リスクの整理は [`docs/migration-estimate.md`](docs/migration-estimate.md) を参照してください。

## その他の注意（本番公開時）

- **microCMS**：本番ドメインからの取得が許可されているか確認する。
- **Adobe Fonts（Typekit）**：本番ドメインをキットの許可ドメインに登録する。
- **リダイレクト**：旧 URL がある場合は **301** を検討する（`.htaccess` またはサーバー設定）。
- **Google Search Console**：URL 変更時はプロパティと sitemap の送信を忘れない。
