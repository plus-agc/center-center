# サーバー移転見積もり（さくらのサーバー）

## 決定事項

**本番ホスティングはさくらインターネットのサーバー（レンタルサーバ等）に決定しました。**  
このサイトは **静的ファイル（`npm run build` → `dist`）の公開** が中心のため、一般的なレンタルサーバの **ドキュメントルートへの配置 + SSL** で運用できます。

---

## 1. 前提（このリポジトリの性質）

| 項目 | 内容 |
|------|------|
| 形態 | `npm run build` で `dist` に出力する **静的 HTML/CSS/JS**（PHP・DB 不要） |
| 外部連携 | クライアントから **microCMS** の API を `fetch`（`js/news.js` / `js/event.js`） |
| 要設定 | `webpack.config.prod.js` の sitemap で `base: 'https://example.com'` のため、**本番ドメインに変更**が必要 |

FTP/SFTP のパスワード等は **リポジトリに含めない**でください（エディタ設定や CI のシークレットで管理）。

---

## 2. さくらでの運用イメージ

| 項目 | 内容 |
|------|------|
| デプロイ | ローカルまたは CI で `npm run build` 後、**`dist` 以下を公開ディレクトリにアップロード**（FTP/SFTP/rsync 等） |
| SSL | サーバー／スタンダードのコントロールパネルから **無料 SSL（Let's Encrypt 等）** を有効化（プラン・マニュアルに従う） |
| 404 | マルチページ HTML のため、必要に応じ **`404.html`** と **`.htaccess`**（`ErrorDocument 404`）を公開ルートに配置 |
| 費用 | **レンタルサーバ**: プランにより月 **数百円〜**（[公式料金](https://rs.sakura.ad.jp/) で確定）。**VPS** は月数千円〜だが本サイト単体では過剰になりやすい |

---

## 3. 作業内訳と工数目安（さくら前提・1 人あたり）

| # | 作業 | 目安工数 | 備考 |
|---|------|----------|------|
| 1 | 本番 URL・`robots.txt`・**sitemap の正式ドメイン**・内部リンクの最終確認 | 0.5〜1.0h | `example.com` を解消 |
| 2 | `npm run build` と `dist` の確認、**microCMS** 表示の本番相当での確認 | 0.5〜1.0h | 可能なら検証用サブドメインで先行 |
| 3 | **さくら側**: 公開ディレクトリの決定、`dist` の配置、**404 / `.htaccess`**、キャッシュや MIME の問題があれば調整 | 1.0〜2.5h | ディレクトリ階層・既存サイトとの同居で変動 |
| 4 | **DNS**（A/CNAME またはネームサーバ）、**SSL** 有効化・反映待ち、本番再テスト | 0.5〜1.5h | 伝播で半日〜1 日かかることも |
| 5 | 旧サーバー退避、**301 リダイレクト**要否 | 0.5〜1.0h | ドメイン・パス変更時 |
| | **合計** | **約 3.5〜8.5 時間** | 承認・不具合対応で上振れ |

**費用換算の例**（8,000 円/時）: 概算 **2.8 万円〜6.8 万円**（税・予備は別）。

## 4. ランニングコスト（さくら）

| パターン | 月額目安 |
|----------|----------|
| レンタルサーバ（スタンダード等） | プラン表に準拠（多くは **数百円〜数千円 / 月**） |
| VPS | **数千円〜**（運用・セキュリティ更新の工数が増えやすい） |

※ **Vercel は採用しない**ため、当プロジェクトのインフラ費は上記さくら側のみを見込む形になります。

---

## 5. リスク・忘れがちなタスク

- **Google Search Console** のプロパティ追加・sitemap 送信（URL が変わる場合）。
- **Adobe Fonts（Typekit）**: 本番ドメインをキットの許可ドメインに登録（フォントが読み込めない場合）。
- 旧 URL がある場合の **301 リダイレクト**（`.htaccess` またはサーバー設定）。
