# サーバー移転見積もり（Vercel / さくらのサーバー候補）

## 1. 前提（このリポジトリの性質）

| 項目 | 内容 |
|------|------|
| 形態 | `npm run build` で `dist` に出力する **静的 HTML/CSS/JS**（PHP・DB 不要） |
| 外部連携 | クライアントから **microCMS** の API を `fetch`（`js/news.js` / `js/event.js`） |
| 要設定 | 本番 URL は `webpack.config.prod.js` の sitemap 設定で `base: 'https://example.com'` となっているため、**実ドメインに変更**が必要（プレースホルダの解消） |

移転作業量は、**Vercel・さくらのいずれも小〜中**で、主な違いは**運用方法・月額費用・社内手続き**です。  
（ローカルに保存している FTP/SFTP 接続設定は**平文の秘密をリポジトリに置かない**のが推奨です。）

---

## 2. 候補比較

|  | **Vercel** | **さくらのレンタルサーバ等** |
|---|------------|------------------------------|
| 向いている | Git 連携・プレビュー URL、デプロイの自動化 | 既存がさくら中心・「ビルド済みを所定ディレクトリへ配置」の運用に馴染む場合 |
| 本番 | `dist` を配信、または `npm run build` を CI でビルド | `dist` を **Web 公開ディレクトリ**にアップロード（従来型の静的配信） |
| 費用 | **Hobby: 無償**（利用規模に応じ Pro 等を検討）／**Pro: 月額 約 20 ドル前後+税** が目安 | プランにより**月 数百円〜数千円**（公式料金表で確定） |
| SSL | 自動（Let's Encrypt） | 管理画面等で有効化 |
| 注意 | チーム・帯域・サポート方針で課金プラン要否 | ディレクトリ・ドメイン・権限（FTP/SSH）の整理 |

## 3. 作業内訳と工数目安（1 人あたり・概算）

| # | 作業 | 目安工数 | 備考 |
|---|------|----------|------|
| 1 | 本番 URL・`robots.txt`・**sitemap の正式ドメイン**・内部リンクの最終確認 | 0.5〜1.0h | 必ず `example.com` を解消 |
| 2 | ビルド検証（`npm run build`）、`dist` 本文と microCMS 表示の確認 | 0.5〜1.0h | 可能ならステージング URL で先行確認 |
| 3a | **Vercel**: リポジトリ連携、**Build Command** `npm run build`、**Output** `dist` 等 | 1.0〜2.0h | 初回のみ |
| 3b | **さくら**: `dist` を公開ルート配下に配置、**404** まわり（必要なら `.htaccess`） | 1.0〜2.5h | ディレクトリ構成に依存 |
| 4 | **DNS 切替**、SSL 反映待ち、本番再テスト | 0.5〜1.5h | 伝播で半日〜1 日かかることも |
| 5 | 旧サーバー退避（バックアップ）、**301 リダイレクト**要否 | 0.5〜1.0h | ドメイン変更時は要検討 |
| | **合計** | **約 4〜10 時間** | 不具合・社内承認の往復があれば上振れ |

**費用換算の例**（人件費 8,000 円/時とした場合）: 概算 **3.2 万円〜8 万円**（税・予備枠は別）。外注化する場合は 1.5〜3 倍程度を目安にすることが多い。

## 4. ランニングコスト目安

| パターン | 月額目安 |
|----------|----------|
| Vercel Hobby | 0 円（利用規模・Pro 要否は公式の最新条件で確認） |
| Vercel Pro | 月 約 20 ドル+税 前後（為替で変動） |
| さくら レンタルサーバ | プランで月 数百円〜（公式表で確定） |
| さくら VPS 等 | 月 数千円〜（運用工数は増えやすい） |

---

## 5. 推奨の目安

- **Git から自動デプロイし、本番/プレビューを分けたい** → **Vercel** を第一候補。
- **従来どおり「ビルド結果を所定フォルダへ配置」**でよい、**国内レンタルで統一**したい → **さくら**。

---

## 6. リスク・追記タスク

- **sitemap / Google Search Console** の新 URL 登録。
- **microCMS** は現状の公開 API 前提でクライアント `fetch`（特別なサーバーサイドは不要な想定）。
- 旧 URL から新 URL への **301 永続リダイレクト**（ドメインやパスが変わる場合は要検討）。
